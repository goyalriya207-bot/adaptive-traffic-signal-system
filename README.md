# Adaptive Traffic Signal System with Emergency Evacuation Support

## Project Overview

This project is a simulation-based traffic management system that aims to reduce traffic congestion and support emergency vehicle movement. The system adjusts traffic signal timings based on traffic conditions and identifies suitable routes for emergency vehicles during critical situations.

## Problem Statement

Traditional traffic signals often use fixed timings, which can lead to unnecessary waiting and traffic congestion. During emergencies, vehicles such as ambulances may face delays due to blocked roads and heavy traffic.

This project aims to:
- Reduce traffic congestion
- Optimize signal timings based on traffic density
- Support emergency vehicle movement
- Provide alternative routes when roads are blocked

## Key Features

- Shortest Route Selection
- Traffic-Based Signal Control
- Emergency Vehicle Priority
