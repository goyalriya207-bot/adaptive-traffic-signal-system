# Adaptive Traffic Signal System with Emergency Evacuation Support

## Brief Description

Adaptive Traffic Signal System with Emergency Evacuation Support is a simulation-based project developed using C++. The project aims to improve traffic management by adjusting signal timings according to traffic conditions and supporting efficient movement of emergency vehicles through optimized route selection.

---

## Problem Statement / Objective

Traditional traffic signals often operate on fixed timings, which can lead to traffic congestion and increased waiting time. During emergency situations, vehicles such as ambulances and fire trucks may face delays due to traffic conditions and road blockages.

The objectives of this project are:

- Reduce traffic congestion at junctions
- Adjust signal timings based on traffic density
- Provide priority to emergency vehicles
- Identify alternative routes when roads are blocked
- Apply DSA, OOP, and File Handling concepts in a real-world scenario

## Project Setup / Installation Instructions

1. Clone the repository.
2. Open the project in VS Code or any C++ IDE.
3. Compile the source code.
4. Run the executable file.

```bash
git clone <repository-link>
cd <project-folder>
g++ main.cpp -o traffic_system
./traffic_system
```
